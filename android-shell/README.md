# Ajuda Mútua - Android shell

Este projeto é um shell Android simples que abre a versão web de produção do Ajuda Mútua em WebView.

Antes de gerar o APK, substitua `https://SEU-DOMINIO-AQUI` em `app/build.gradle` pela URL HTTPS definitiva do app.

O backend e o banco ficam fora do APK. O APK apenas apresenta o aplicativo web publicado, preservando login e dados no servidor.
